# أكاديمية الجيتار 🎸

تطبيق أندرويد تعليمي كامل للسلالم والمقامات على الجيتار، من المبتدئ إلى عزف أي أغنية. صممت منهجه لجنة من عازف محترف ومايسترو ومدرس موسيقى، وبرمجه المبرمج.

## تحميل التطبيق

نزّل ملف `guitar-academy.apk` من صفحة [الإصدارات](../../releases/latest) على جوالك وافتحه. إن طلب الجهاز السماح بالتثبيت من مصادر غير معروفة فوافق.

يُبنى الملف تلقائياً من آخر نسخة في المستودع عبر GitHub Actions.

## المحتوى

- **115 درساً في 5 مستويات:** المبتدئ، المتوسط، المتقدم، المقامات العربية، والاحتراف (عزف أي أغنية)، مع اختبار عبور لكل مستوى.
- **كل درس:** هدف، آراء اللجنة الثلاثة، شرح صوتي عربي خطوة بخطوة، زند متحرك يضيء النوتات مع صوت الجيتار، تمرين بالمترونوم، اختبار، وقائمة إتقان.
- **وضع المشاهدة:** يشغّل الدرس كاملاً تلقائياً كأنه فيديو.
- **المقامات:** 17 مقاماً و9 أجناس، مع ربع التون بالبِند وعلامة واضحة على الزند.
- **محلل المقام:** ارفع أغنية أو سجّل مقطعاً، فيحدد المقام والقرار مع نسبة الثقة، ويعرض الدليل بالسنت لكل درجة، وخطاً زمنياً للتحويلات. يعمل على الجهاز دون إنترنت.
- **الأدوات:** مستكشف السلالم والمقامات، مكتبة الكوردات، الدوزان بالمايكروفون (مع وضع ربع التون)، المترونوم و9 إيقاعات عربية، تدريب الأذن، كاشف المفتاح، محوّل المفتاح، حاسبة الكابو.
- **يعمل دون إنترنت**، ويحفظ تقدمك على الجهاز.
